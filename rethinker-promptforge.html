Rethinker Prompt Forge

A robotic manipulation research project that rethinks failure cases via vision-language reasoning and forges embodied prompts in a closed loop — with the governance rules that keep its results honest.

Python · RoboTwin sim vLLM + cloud critic Occlusion-aware perception

Overview

Prompt optimization for embodied agents is easy to do and hard to do honestly: a lucky seed, an all-knowing detector, or a single-episode delta can make any edit look like an improvement. This project builds the loop end to end — RoboTwin rollouts under occlusion, a video-stage critic that rethinks each failure, and an optimizer that makes bounded prompt edits — and then surrounds it with the gates that keep the results believable.

The embodiment is a single-arm franka-panda in RoboTwin (mirroring the Realman-65B target). Perception is deliberately not all-knowing: PhysX raycasts from the head camera plus declarative hidden_by cover rules decide which objects even appear in observations.

The Five-Layer Pipeline

1 — Honest environment

Every task passes an actor-mapping audit; grasps and places go through RoboTwin actor-level skills. lift() physically verifies the carry — a kinematically successful but empty grasp is retried once, then reported as failure.

2 — Task-set governance

Admission requires a reachability smoke test, stable scene generation, and discrimination: neither trivially solvable nor physically impossible, but in the "strategy-dependent" band. Held-out val tasks use different seeds/variants. Current set: train 4 / val 4.

3 — Forge loop

Per epoch: train rollouts → video-stage critic on failures → optimizer bounded edits → candidate registered → validation gate. A faulthandler watchdog guards against SAPIEN/GPU contention wedges.

4 — Quality gate

4 episodes per val task, never single-episode deltas. Lexicographic composite of (success rate, −average steps), with steps counted over successful episodes only — a candidate must not "improve" by failing fast.

5 — Confirmation & promotion

A gate accept is a nomination, not a result. Promotion requires a paired confirmation: 48 interleaved A/B episodes, positive only when the candidate wins overall and is not worse on any single task.

Implementation Highlights

  • Occlusion as a first-class citizen: raycast visibility + cover rules mean the planner must reason about what it cannot see — the "rethinker" cases the project is named after.
  • Ablation baselines: monolithic planner, no-hidden-hypothesis, and no-reflection variants share one prompt registry, so the loop's gains can be attributed.
  • Physical-variance discipline: bands overlap easily at small N — a confirmation delta must be visible in at least two tasks, not one.
